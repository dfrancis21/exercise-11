Task 2: Interactive penguin plot

The scatterplot below compares penguin bill depth and bill length. The points are colored by species. Hover over a point to see its species, sex, island, bill depth, and bill length.

Code 
penguin_plot <- ggplot(
  penguins_clean,
  aes(
    x = bill_dep,
    y = bill_len,
    color = species,
    shape = species,
    text = tooltip
  )
) +
  geom_point(size = 3, alpha = 0.85) +
  scale_color_manual(
    values = c("Adelie" = "darkorange", "Chinstrap" = "purple", "Gentoo" = "cyan4")
  ) +
  labs(
    title = "Penguin Bill Depth and Bill Length",
    x = "Bill depth (mm)",
    y = "Bill length (mm)",
    color = "Species",
    shape = "Species"
  ) +
  theme_light()

ggplotly(penguin_plot, tooltip = "text")

## Task 2: Interactive penguin plot

The scatterplot below compares penguin bill depth and bill length. The points are colored by species. Hover over a point to see its species, sex, island, bill depth, and bill length.

```{r}
#| label: setup
#| include: false

library(tidyverse)
library(plotly)
library(glue)
library(leaflet)
library(scales)

# Use the penguins dataset included with the assignment's specified R version.
penguins <- datasets::penguins

# Keep observations with the information needed for the plot and dashboard.
penguins_clean <- penguins |>
  drop_na(sex, species, island, bill_len, bill_dep, body_mass) |>
  mutate(
    tooltip = glue(
      "Species: {species}<br>",
      "Sex: {sex}<br>",
      "Island: {island}<br>",
      "Bill depth: {bill_dep} mm<br>",
      "Bill length: {bill_len} mm"
    )
  )
```

```{r}
penguin_plot <- ggplot(
  penguins_clean,
  aes(
    x = bill_dep,
    y = bill_len,
    color = species,
    shape = species,
    text = tooltip
  )
) +
  geom_point(size = 3, alpha = 0.85) +
  scale_color_manual(
    values = c("Adelie" = "darkorange", "Chinstrap" = "purple", "Gentoo" = "cyan4")
  ) +
  labs(
    title = "Penguin Bill Depth and Bill Length",
    x = "Bill depth (mm)",
    y = "Bill length (mm)",
    color = "Species",
    shape = "Species"
  ) +
  theme_light()

ggplotly(penguin_plot, tooltip = "text")
```
